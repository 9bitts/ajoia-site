# Ajoia Brasil — Portal

Novo site da **Associação Brasileira de Jornalistas Independentes e Afiliados**.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Produção

```bash
npm run build
npm start
```

## Estrutura editorial

Padrão inspirado em NYT, Guardian, BBC, Reuters e Revista Oeste:

- Capa com hero + rail de destaques
- Ticker de últimas
- Seções: Política, Estado, Cidade, Mundo, Cultura, Opinião, Editorial, Tema Livre
- Colunistas
- Institucional: Quem Somos, Diretrizes, Expediente, Contato, Mídia Kit
- Página de artigo com related stories

## Conteúdo

Textos e posicionamento baseados no portal atual [ajoiabrasil.com.br](https://ajoiabrasil.com.br/).
